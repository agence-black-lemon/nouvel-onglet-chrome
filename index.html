Recopie d'écran

  1. Allume la télé et vérifie que ton Mac est sur le même Wi-Fi que l'Apple TV.
  2. Clique sur l'icône Centre de contrôle en haut à droite de l'écran (les deux interrupteurs), puis sur Recopie de l'écran.
  3. Choisis l'Apple TV. Si un code s'affiche sur la télé, tape-le sur ton Mac.
  4. Pour arrêter : même menu, clique à nouveau sur l'Apple TV.

Astuce : dans le même menu, choisis « Utiliser comme écran séparé » pour garder tes notes sur ton Mac pendant une présentation.
